
# Raspberry Pi Picoを使用した自動給水システム
<img width="600" height="800" alt="PXL_20260906_053825612" src="https://github.com/user-attachments/assets/b3afdaae-24b4-45d2-8552-eea625a1e893" /><br>

## 概要
Raspberry Pi Picoと土壌湿度センサーを使用した自動給水システムです。

土壌湿度センサーから土壌水分量の値を6時間ごとに取得し、<br>
設定した閾値を下回った場合に給水ポンプを3秒間動作させます。<br>

また、2つのボタンによる手動操作にも対応しています。<br>
左ボタンで現在の土壌湿度の状態をそれぞれ、<br>
25%以下→SUPER DRY、25%~75%→DRY、75%以上→WETをモニタに表示します。<br>
右ボタンでは1秒間だけ給水させることができます。

## 動作

自動制御

1.土壌湿度センサーから土壌水分量の値を取得する。

2.取得した値と設定した閾値を比較する。

3.土壌水分量が25%以下の場合、リレーをONにして給水ポンプを3秒間動作させる。

4.ポンプを停止し、6時間後に再度測定する。

手動操作

左ボタン押下時：現在の土壌湿度レベル（SUPER DRY / DRY / WET）を測定し、モニタに表示する。
<img width="400" height="225" alt="左ボタン操作" src="https://github.com/user-attachments/assets/726ff29e-1038-4877-ada2-7a23dc7cae41" />

|土壌水分量|センサの値|表示名|
|---:|---|---|
|25%以下|x >= 3500|SUPER DRY|
|25%~75%|2500 < x < 3500|DRY|
|75%以上|x <= 2500|WET|
* xを土壌湿度の値とする。
また値が4000で湿度0%、2000で湿度100%として計算しています。

右ボタン押下時：水中ポンプを1秒間だけ動作させて停止する。

## 技術的な工夫・改善点など

### 1. NPNトランジスタによるリレー駆動回路の設計
* **課題:** 
  当初、Raspberry Pi Pico の GPIO ピンからリレーモジュールへ直接接続していましたが、リレーがオンになったままオフにならない症状が出ていました。<br>
  テスターを使ってHIGHとLOWの確認をしたところそれぞれ電圧が出ていたので、プログラムとしては問題がなさそうでした。<br>

* **解決策:** 
  Raspberry Pi Picoから直接リレーに接続するのではなく、NPNトランジスタを中間に配置し、リレーのオンとオフが正常に動くようになりました。<br>

### 2. 電源系統の分離によるノイズ・電圧降下対策
* 水中ポンプ動作時のノイズや急速な電圧降下によりRaspberry Pi Picoが一時的に電源オフになるような影響を防ぐため、マイコン用電源と水中ポンプ駆動用電源の系統を物理的に分離しました。

### 3.delayを使ったタイマーカウント
* 現在は<br>
sleep_ms(10); <br>
ms_counter += 10; //uint64_t ms_counter = 0;として設定<br>
と記載しています。<br>
もとはsleep_ms(1000);で設定していましたが、ボタンの反応速度が遅かったので現在の記載方法に変更しています。<br>

ただ10m秒ごとにループを回すことになり消費電力が高くなるので、<br>
ディープスリープ機能のようなものを実装して、割り込み機能で起こすようなシステムに出来るか調べて改修予定です。<br>
