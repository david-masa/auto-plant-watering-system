
# Raspberry Pi picoを使用した自動植物給水システム
<img width="600" height="800" alt="PXL_20260906_053825612" src="https://github.com/user-attachments/assets/b3afdaae-24b4-45d2-8552-eea625a1e893" /><br>
## 概要

Raspberry Pi Picoと土壌湿度センサーを使用した自動植物給水システムです。

土壌湿度センサーからアナログ値を定期的に取得し、設定した閾値を下回った場合に給水ポンプを動作させます。<br>
ポンプは一定時間動作した後に停止し、再度センサー値を確認します。

また、2つのボタンによる手動操作にも対応しており、左ボタンで現在の土壌湿度ステータス（SUPER DRY / DRY / WET）をOLED画面に表示し、右ボタンで水中ポンプを1秒間だけ手動テスト動作させることができます。

センサー値の取得、乾燥判定、ポンプ制御、OLED表示を、組み込みソフトウェアとして実装しています。

## 動作


自動制御

1.土壌湿度センサーからアナログ値を取得する。

2.取得した値と設定した閾値を比較する。

3.土壌が乾燥している場合、リレーをONにして給水ポンプを一定時間動作させる。

4.ポンプを停止し、一定時間後に再度測定する。

手動操作

左ボタン押下時：現在の土壌湿度レベル（SUPER DRY / DRY / WET）を測定し、OLEDディスプレイに表示する。

右ボタン押下時：水中ポンプを1秒間だけ動作させて停止する。

## 配線

| ピン番号 | 接続先 |
|---:|---|
| 31 (GP26 / ADC0) | 土壌水分センサー AO |
| 20 (GP15) | 1kΩ → S8050 ベース |
| 36 (3.3V OUT) | 土壌水分センサー VCC |
| 38 (GND) | 土壌水分センサー GND |
| 38 (GND) | S8050 エミッタ |
| VBUS | 18650充電モジュールの出力 |
| GND | 18650充電モジュールのGND |
| S8050 コレクタ | リレーモジュール IN |
| リレーモジュール COM | 単4ニッケル水素電池×4 の＋ |
| リレーモジュール NO | 水中ポンプ＋ |
| 水中ポンプ－ | 単4ニッケル水素電池×4 の－ | 
| 6 (GP4 / SDA) | OLEDディスプレイ SSD1306 SDA |
| 7 (GP5 / SCL) | OLEDディスプレイ SSD1306 SCL |
| 36 (3.3V OUT) | OLEDディスプレイ SSD1306 VCC |
| 38 (GND) | OLEDディスプレイ SSD1306 GND |
|21 (GP16)|左ボタン|
|22(GP17)|右ボタン|
