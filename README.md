
# Raspberry Pi Picoを使用した自動植物給水システム
<img width="600" height="800" alt="PXL_20260906_053825612" src="https://github.com/user-attachments/assets/b3afdaae-24b4-45d2-8552-eea625a1e893" /><br>

## 概要
Raspberry Pi Picoと土壌湿度センサーを使用した自動植物給水システムです。

土壌湿度センサーから土壌水分量の値を6時間ごとに取得し、設定した閾値を下回った場合に給水ポンプを3秒間動作させます。<br>

また、2つのボタンによる手動操作にも対応しています。<br>
左ボタンで現在の土壌湿度の状態をそれぞれ、<br>
25%以下→SUPER DRY、25%~75%→DRY、75%以上→WETをモニタに表示します。<br>
右ボタンでは1秒間だけ給水させることができます。

## 動作

自動制御

1.土壌湿度センサーから土壌水分量の値を取得する。

2.取得した値と設定した閾値を比較する。

3.土壌水分量が25%以下の場合、リレーをONにして給水ポンプを3秒間動作させる。

4.ポンプを停止し、6時間後に再度測定する。

手動操作

左ボタン押下時：現在の土壌湿度レベル（SUPER DRY / DRY / WET）を測定し、モニタに表示する。

右ボタン押下時：水中ポンプを1秒間だけ動作させて停止する。

## 💡 技術的な工夫・トラブルシューティング

### 1. NPNトランジスタによるリレー駆動回路の設計
* **課題:** 
  当初、Raspberry Pi Pico の GPIO ピンからリレーモジュールへ直接接続し、テスターを使ってHIGHとLOWの確認をしたところそれぞれ電圧が出ていたにもかかわらず、リレーを正常にスイッチング動作させることができませんでした。
* **解決策:** 
  Raspberry Pi Picoから直接リレーに接続するのではなく、NPNトランジスタを中間に配置し、リレーの動作を安定したものにしました。

### 2. 電源系統の分離によるノイズ・電圧降下対策
* 水中ポンプ動作時のノイズや急速な電圧降下がRaspberry Pi Picoに及ぼす影響を防ぐため、マイコン用電源と水中ポンプ駆動用電源の系統を物理的に分離しました。

## 🚀 今後の展望（ESP32 への拡張計画）

現在はRaspberry Pi Picoによるスタンドアロン環境で動作していますが、今後は Wi-Fi / Bluetooth 通信モジュールを搭載した **ESP32** への移設を計画しています。

* **IoT化とデータの可視化:**

* **スマートフォン連携:** 
  「乾燥状態が一定時間続いた場合」や「給水完了時」に、LINEボットなどを経由してスマホへ通知を送る機能を実装予定。
